Instrucciones
Utiliza tu cliente SQL y redacta los siguientes scripts de creación de Dominios de grado empresarial que resolverán este reto arquitectónico:

1-El Dominio Monetario Bancario:
    Escribe y ejecuta un comando CREATE DOMAIN ... para conformar el tipo exclusivo monto_financiero.
    Este dominio se basará obligatoriamente sobre el tipo de dato financiero y preciso de PostgreSQL con 15 dígitos de longitud y 2 dígitos decimales contables oficiales.
    Debe integrar de nacimiento un constraint (CHECK) de validación para rechazar automáticamente cualquier valor por debajo del cero matemático absoluto.
2-El Dominio de Identificación Fiscal / Cadena No Vacía:
    Escribe y ejecuta el comando CREATE DOMAIN ... para crear el tipo texto_obligatorio que envolverá las columnas de tax_id o nombres fiscales.
    Apóyate en el tipo base VARCHAR(100) agregándole al dominio el constraint intrínseco de rechazar cadenas que consten meramente de un texto vacío o puros espacios en blanco ineficaces: CHECK (VALUE <> '' AND LENGTH(TRIM(VALUE)) > 0).
